Rota pública desativada por segurança

Para impedir ataques de escalação de privilégios, a API pública de promoção de administradores foi completamente desativada. As promoções agora devem ser feitas diretamente no terminal local usando as credenciais privadas do servidor.

Como promover um usuário:

Abra o terminal na pasta do projeto administrativo e execute o script local:

node set_admin.js "usuario@email.com"

Ou use o UID do Firebase:

node set_admin.js "UID_DO_USUARIO"
Arquivo de automação: set_admin.js ● Execução Local
